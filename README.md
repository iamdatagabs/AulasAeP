# Algoritmos e Programação — Materiais de aula

Repositório de apoio aos códigos e exemplos executados no curso de Algoritmos e Programação do Mestrado em Computação da Universidade Estadual de Ponta Grossa (UEPG).

## Objetivo

Organizar exemplos de programação utilizados em atividades de ensino, facilitando consulta, reprodução e continuidade dos exercícios.

## Como utilizar

- Consulte os diretórios e arquivos-fonte para localizar cada exemplo.
- Verifique comentários e dependências antes de executar.
- Utilize os códigos como material didático, adaptando-os aos objetivos de cada atividade.

## Natureza do repositório

Arquivo educacional de disciplina. Os exemplos não representam necessariamente aplicações prontas para produção nem recebem manutenção como produto independente.
